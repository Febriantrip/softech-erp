ERP DISTRIBUTOR V6 - AURORA BACK OFFICE UI EDITION

This overlay keeps the V6 ERP transaction engine intact and applies the visual
system from the attached aurora-pos-backoffice reference, including:

- Light blue/violet Aurora canvas and ambient gradients
- Floating rounded glass sidebar
- Floating glass topbar
- Back-office typography scale and compact spacing
- Violet-to-blue active states and primary actions
- Glass KPI cards and operational panels
- Light data tables, forms, filters, modals, and workbenches
- Matching status badges, tabs, master cards, finance cards, approval cards
- Matching Purchase/Warehouse command-center cards
- Matching document detail surfaces and audit timeline
- Responsive tablet/mobile treatment

INSTALL
1. Stop Vite with Ctrl+C.
2. Extract this ZIP into the ROOT of your existing V5/V6 ERP project.
3. Choose Replace / Overwrite All.
4. Run npm run dev or START_ERP.bat.

No new npm dependency is required.
